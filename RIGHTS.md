# Rights and licensing status

## Project code and documentation

This repository is a public feasibility demonstration. No project-wide open-source software license has been selected for the project code and documentation at this stage. Public visibility alone is not an open-source license. A suitable license and the relevant contributor/maintainer roles need to be confirmed before a package release or general reuse grant.

No new copyright ownership, exclusive authorship, patent permission or endorsement is asserted by publication. See AI_ASSISTANCE.md for the provenance of AI-assisted material.

## Third-party data and dependencies

The raw CSV files are unmodified, factual metadata responses from the NASA OSDR Biological Data API. Source URLs, retrieval times and hashes are preserved in manifest.json. Derived tables retain field-level source provenance. NASA's source policies and any applicable study-specific terms govern those source materials; this repository does not relicense them. See DATA_SOURCES.md.

The optional webR runtime and its dependencies are not vendored. Their own licenses apply; package-lock.json records the resolved dependency versions and available license metadata. No third-party source repository or publication is bundled.

The code and diagnostic outputs are experimental. They do not establish biological equivalence or suitability for a scientific analysis, and have not undergone a complete legal or scientific review.
